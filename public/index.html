② 全局有序事件（≤ 128）

0 / 128

每行：[序号] 线程 操作 [地址] [reclaim=地址:地址]。 操作：load / publish / reconfirm / read / retire / scan / reuse （支持中文：装载/发布/再次确认/读取/摘链退役/扫描回收/复用）。
publish null 撤销危险指针；scan 不带清单时回收全部“已退役且无人保护”节点。

③ 复核结论

尚未复核。录入链表与事件后点击「复核」。
分析在 Web Worker 内执行，不会阻塞页面。
规则：同代次危险指针已发布 + 发布后成功再确认当前头指针 + 读取瞬间头指针未变，三者齐备读取才合法； 扫描仅回收未受任何线程保护的退役节点；地址复用仅限已回收节点并产生新代次。
